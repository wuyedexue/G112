# 随机人物生成器 - Python桌面版

基于职业收集数据库，随机组合生成虚拟人物档案的独立桌面应用。

## 功能

- 随机生成完整人物档案（姓名、性别、年龄、职业、性格、生活习惯、不良习惯、家庭关系）
- 独立桌面窗口，PyQt6 构建
- 支持历史记录查看和清空
- 可打包为独立exe，无需Python环境即可运行

## 快速启动

### 方式一：直接运行（需要Python 3.9+）

双击 `启动随机人物生成器.bat`，首次运行会自动安装PyQt6依赖。

或手动运行：
```bash
pip install PyQt6
python main.py
```

### 方式二：打包为独立exe

双击 `打包为exe.bat`，打包完成后在 `dist/` 目录找到 `随机人物生成器.exe`，可以拷贝到任何Windows电脑运行。

## 文件说明

| 文件 | 说明 |
|------|------|
| main.py | 主程序（UI + 逻辑） |
| data.py | 数据模块（职业、性格、习惯等数据池） |
| requirements.txt | Python依赖 |
| 启动随机人物生成器.bat | 一键启动脚本 |
| 打包为exe.bat | 打包为独立可执行文件 |

## 数据来源

全部来自职业收集文件夹：
- 职业池：200+ 职业，覆盖25个大类
- 性格：4维度组合（基础 + 工作强化 + 人际风格 + 决策风格）
- 生活习惯：25条
- 不良习惯：24条
- 家庭关系：8种家庭结构 x 20种家庭问题

## 环境要求

- Python 3.9+
- Windows 10/11
- 打包后的exe无需Python环境

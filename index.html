Coordinate Tool MVP

坐标识别工作台

上传图片后生成可替换 OCR 候选点，输入多个范围坐标，按多边形或包围盒判断入域，人工确认后导出 CSV/JSON。

最短启动路径
npm install
npm start
打开 http://localhost:3000

1. 上传图片与识别

把地图、截图或坐标图上传到这里

当前 MVP 使用 mock OCR 返回 3 个候选点，后续真实识别服务可直接替换 /api/recognize。

请先上传图片，再点击“识别坐标”。也可以手动添加候选坐标。

2. 输入范围坐标

多边形模式适合不规则区域；包围盒模式会取所有范围点的最小/最大 x、y 形成矩形。

3. 候选坐标确认

4. 导出 CSV / JSON

仅导出“已确认”的坐标，名称按 前缀_001、前缀_002 递增。
